CURRENT STATUS

What is SignAR?

SignAR is a browser-based Filipino Sign Language recognition system. Holistic-v4 tracks coordinated two-hand, face, and body cues across 30 ordered frames, and the live decoder segments sign streams at stable class changes or pauses. The installed model still recognizes its existing fingerspelling labels with the older hand-v3 schema; new words, phrases, dynamic signs, and holistic cues become recognizable after a matching model candidate is trained and transferred. Evaluation metrics describe the recorded dataset and may differ across signers, cameras, and environments.

DECODER PIPELINE

How SignAR works

  • Camera: captures a local video stream without uploading it.
  • MediaPipe tracking: a pinned Tasks Vision HolisticLandmarker tracks both hands, face, and body with GPU and CPU fallback. A separate face check indicates when multiple people are in view while decoding continues.
  • Shared normalizer: converts each frame into 422 values for two hands, body pose, facial cues, and cue presence. Thirty ordered frames preserve sign movement.
  • Streaming decoder: sends ordered holistic sequences to a compatible model, smooths probabilities, and segments a continuous stream at stable sign changes or pauses. Manifest metadata distinguishes letters, word signs, phrase signs, and dynamic signs.
  • TensorFlow.js: loads labels and output dimensions from a compatible, validated model manifest, then benchmarks WebGPU, WebGL, WebAssembly, and CPU to select the fastest backend supported by this device.
  • Sentence and voice: appends segmented sign units using configured display text and speaks after a pause.

Model status: predictions are enabled after a compatible model and its evaluation files pass the SignAR validation profile.

ACCESSIBILITY SUPPORT

A flexible recognition system

SignAR converts model-supported FSL signs into readable text using local camera processing. Its vocabulary can expand as reviewed words, phrases, and dynamic signs are added to the model. Accepted labels and configured meanings appear in a two-dimensional card over the camera preview; the current release does not spatially anchor 3D content.
